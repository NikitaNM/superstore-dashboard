# superstore-dashboard

Интерактивный дашборд в Power BI для анализа продаж и прибыли сети Superstore.

## 📊 О проекте
Проект демонстрирует полный цикл BI-разработки: от подготовки данных в Python до построения трёхстраничного дашборда в Power BI с бизнес-выводами.

## 🗂 Данные
- **Источник:** Superstore Sales (10 800 записей)
- **После очистки:** 9 994 строки, 23 колонки
- **Период:** 2015–2018
- **Целевые метрики:** Sales, Profit, Orders, Discount

## 🛠 Стек
- **Python:** pandas, numpy, matplotlib (EDA, подготовка данных)
- **Power BI:** визуализация, DAX, интерактивные фильтры

## 📈 Страницы дашборда
1. **Обзор продаж** — KPI, категории, топ-продукты, динамика, карта, сегменты.
2. **Углублённый анализ** — прибыль по подкатегориям, влияние скидок, топ-штаты.
3. **Выводы** — ключевые инсайты и рекомендации.

## 💡 Ключевые инсайты
- Technology — лидер по продажам (36,4%).
- Consumer — ключевой сегмент (~50% продаж).
- Убыточные подкатегории: Tables, Bookcases.
- Скидки выше 30% ведут к убыткам.
- Топ-регионы: California, New York.
